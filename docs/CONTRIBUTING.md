# 贡献指南

## 提交 Issue
请说明问题现象、复现步骤、预期结果和实际结果；功能建议请描述使用场景。

## 分支约定
- `main`：稳定版本。
- `dev`：集成开发分支。
- `feature/<功能名>`：功能开发分支。
- `fix/<问题名>`：缺陷修复分支。

## 推荐流程
1. 从 `dev` 创建功能分支。
2. 完成修改并进行本地测试。
3. 提交清晰的 commit，例如 `feat: add material search`。
4. 向 `dev` 发起 Pull Request。
5. 经检查后合并；稳定后再将 `dev` 合并到 `main`。

## 代码要求
保持命名清晰、避免提交数据库和个人上传文件；涉及数据变更时说明测试步骤。
